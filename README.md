# Offline Kanban Tool

A high-performance, privacy-focused Kanban board designed for professional task management. This tool is a single-file application built with Vanilla JavaScript and CSS, requiring no installation, no database, and no internet connection.

## ✨ Key Features

* **Local-First Privacy:** All tasks and data are stored directly in your browser's `localStorage`. No information is ever sent to a server, ensuring total privacy.
* **Intuitive Kanban Board:** Organize your workflow by dragging and dropping tasks between columns: **To Do**, **In Progress**, **Waiting for Response**, and **Done**.
* **Professional Task Metadata:** Each task includes specific fields for:
    * **Priority:** High, Medium, and Low levels with color-coded indicators.
    * **Assigned To:** Track who is responsible for specific tasks.
    * **Target Dates:** Keep track of deadlines with easy date selection.
    * **Email Subject:** Reference specific email threads or subjects directly in the task.
* **Visual Overdue Alerts:** Tasks that reach or pass their target date are highlighted with red pulsing borders and warning icons to capture immediate attention.
* **Detailed Activity Audit:** A complete history log tracks every change made to a task, including status moves, title edits, description changes, and priority updates.
* **Interactive Commenting:** Add and manage detailed notes within individual task cards. Includes the ability to delete comments when necessary.
* **Powerful Data Portability:**
    * **JSON Import/Export:** Backup your board or merge data from multiple files using "Merge" or "Overwrite" modes.
    * **CSV/Excel Export:** Generate detailed reports including task metadata and full comment history for external analysis.
* **Activity Filter:** Quickly search and view tasks that had activity within a specific custom date range.

## 🛠️ Usage

1. **Download** the `Kanban_V1.html` file from this repository.
2. **Open** the file in any modern web browser (Chrome, Firefox, Edge, or Safari).
3. **Work Offline:** Your progress is saved automatically in your browser's local cache.
